## Objective

the four-primitive state population, eight-task DSL oracle, train/evaluation split

training code belongs in this task.

## Required implementation

- Freeze the exact primitive, state-mask, and task order from the master handoff.
- Implement the typed eight-program executor, required-primitive sets, canonical
  output serialization, and task-specific context schemas.
- Validate sequential dependency by perturbing the required memory result where the
  master protocol requires it.
- Reconstruct the ground-truth `16 x 8` matrix and independently gate
  identifiability and the unique size-four primitive certificate.
- Implement deterministic template/payload IDs, canonical context bytes, normalized
  execution-relevant payload tuples, and collision rejection. Preserve the explicit
  primitive `CONDITION` exception exactly.
- Construct one immutable, ordered 512-prompt evaluation pack with opaque probe keys,
  canonical answers, frozen task/style allocation, Boolean balance, non-Boolean
  distinctness, and a stable checksum.
- Gate literal capability, graph, state, and raw-seed leakage in every model-facing
  string generated by this layer.
- Expose pure functions and plain data structures; do not add a framework or hidden
  mutable registry.
